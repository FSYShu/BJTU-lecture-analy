# 01 · 系统分层整体架构

> 对应产出清单第 1 项。描述输入层 / 处理层 / 引擎层 / 输出层四层流水线，以及与前端、后端、外部 API、存储的对接关系。

└──────────────────────────┬──────────────────────────────────────────┘
                           │ 可供识别的人声音频
                           ▼
┌─────────────────────────────────────────────────────────────────────┐

│   ┌─────────────────┐    ┌──────────────────────────────────────┐   │

                           ▼
┌─────────────────────────────────────────────────────────────────────┐

## 三、分层职责说明

### 输入层
- **CAS 统一身份认证**：通过 Playwright 无头浏览器登录北交大 CAS（`cas.bjtu.edu.cn`），处理图形验证码（OCR 或前端手动透传），登录后 Cookie 导出给 httpx 复用。服务器需校内网络访问（校内部署直连，或 MotionPro VPN 按需拨号）。
- **课程平台回放列表读取（P0-01/FR-17）**：CAS 登录后调用平台 API 1（`teachCalendar.shtml?method=toDisplyTeachCourses`）拉取课次列表，`cId` 写入 `courses.platform_course_id` 用于重复导入识别。
- **单条人工导入（P0-01/FR-01）**：学生/管理员提交一条授权视频 URL 作为备用方式，重复导入可识别。
- **格式兼容（FR-19）**：MP4 / FLV / HLS（平台实际为 HLS），由 `pipeline/steps/download.py` 统一处理。

### 处理层
- **视频下载**：`pipeline/steps/download.py`，先调平台 API 2（`toDisplyCourseSchedDetail`）取三路 HLS 流地址（教师/学生/课件），**MVP 优先下载教师流**（音轨最清晰、含板书口述），ffmpeg-python 拉 HLS → mp4，产物落 `storage/videos/`。
- **音频提取 + 基础降噪**：`pipeline/steps/audio.py`，从教师流 mp4 抽取 16kHz 单声道 wav + 基础降噪（highpass/afftdn），产物落 `storage/audios/`。
- **资源清理**：`core/cleanup.py` 按 `CACHE_RETENTION_DAYS` 清理过期缓存；任务完成且 `CLEANUP_AUDIO_AFTER_TASK=true` 时立即删除中间音频。

### 引擎层
- **讯飞 ASR（`integrations/xfyun_asr.py`）**：输入人声音频，输出带句级时间戳的转写文本。失败按 `XFYUN_ASR_MAX_RETRY` 重试，超时降级。平台已有 VTT 字幕（API 6）可作为补充/校验来源。
- **硅基流动大模型（`integrations/siliconflow_llm.py`）**：输入转写文本分段，输出重点时间点、分层课程总结、两级思维导图。**仅基于本节转写生成**，每条结果记录来源时间戳，避免幻觉。平台已有知识点（API 3 `zsd`）可作为重点时间点的补充/校验，与 LLM 结果做时间点对齐校验（偏差 ≤ 2 秒）。
- **无 GPU**：全部为 HTTPS API 调用，普通云服务器可运行。

### 输出层
- **持久化**：`pipeline/steps/persist.py` 将转写字幕、重点、总结、导图写入 SQLite（见 `docs/03-data-model.md`）。
- **前端展示**：通过 FastAPI REST 接口返回，前端用 Video.js 播放、markmap 渲染导图，所有 AI 生成内容带 `ai_generated=true` 标识。
- **跳转联动**：字幕句 / 重点 / 导图节点均携带视频时间点，前端点击后调用 `player.currentTime(t)`，偏差 ≤ 2 秒（`TIMESTAMP_TOLERANCE_SEC`）。

## 四、关键架构决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 后台任务 | FastAPI BackgroundTasks | MVP 不引入 RabbitMQ/Redis，单服务轻量部署（NFR-10/11）|
| 数据库 | SQLite | 轻量、单文件、普通云服务器可运行（NFR-10）|
| AI 能力 | 全部外部云 API | 无 GPU 依赖，按量付费，符合学生团队预算 |
| 依赖锁定 | uv + pyproject.toml / package-lock.json | 多电脑协作部署一致性 |
| 思维导图 | 两级结构 | 首版仅"课程主题—知识模块—知识点"，不做跨课程知识图谱 |
| 失败隔离 | 单任务独立 try/except + 状态机 | 单任务失败不阻塞其他课程（NFR-05/06）|| 校内网络 | 服务器需访问 `lmt5.bjtu.edu.cn:8880` / `123.121.147.7:88` | 校内部署直连最优；校外则 MotionPro VPN 按需拨号（解析时连，下载完断）。视频流前端直连学校服务器，不走本机带宽 |
